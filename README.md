🐔 El Pollo Loco

A 2D Mexican-style browser game built with JavaScript (OOP), HTML, and CSS.
Play as the main character, fight against different chickens, collect coins, and face the powerful chicken boss in multiple levels.

🎮 Play the Game

⸻

📖 About the Game

El Pollo Loco is a portfolio project that demonstrates skills in Object-Oriented JavaScript, Canvas-based game development, and responsive design.

The game includes:
	•	Multiple levels with increasing difficulty
	•	Different types of chickens (small, medium, and a final boss)
	•	Gravity-based character movement
	•	Coins to collect and score tracking
	•	Sound effects for an immersive experience
	•	A start menu with game instructions
	•	Full responsiveness → works on desktop and mobile

⸻

✨ Features
	•	🧑‍🤝‍🧑 Character can walk, jump, attack, eat, and die
	•	🐔 Various enemies with different behaviors and strengths
	•	👑 Final boss enemy with unique attack/jump patterns
	•	📊 Score system with coin collection
	•	🎶 Sound effects to enhance gameplay
	•	📱 Fully responsive design for desktop & mobile
